What I build

The parts of a Roblox game I work on every day, from the first script to launch day.

  • Game systemsRNG rolls, crafting, quests, clans, skill trees, offline rewards and leaderboards.
  • UI for every deviceHUDs, shops and menus that fit phone, tablet, console and PC without overlapping.
  • Maps and lobbiesHubs, areas, lighting and terrain that look good and stay smooth.
  • MonetizationGame passes, developer products, server luck boosts and a working Robux shop.
  • Anti-cheatServer-side checks that stop remote spam and exploits without hurting real players.
  • 3D modelsLow-poly, textured models made in Blender and imported into Studio.

How a game gets made

The same path every project takes, from idea to live server.

  1. IdeaPick the hook, the loop and what makes players come back.
  2. PrototypeGet the core loop playable on a baseplate, fast.
  3. BuildSystems, map, models, UI and saving data.
  4. PolishAnimations, VFX, sounds and device testing.
  5. LaunchGo live, watch the numbers, keep updating.
